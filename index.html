Crucial BIOS Settings

To prevent installation errors, ensure the following settings are updated in your BIOS menu:

  • Secure Boot: Must be Disabled
  • TPM / Drive Encryption: Must be Disabled
  • SATA Controller Mode: Set to AHCI

How to Install Bliss OS 14 (Step-by-Step Guide)

Follow these simple steps to install Bliss OS 14 on your PC or Laptop:

Prerequisites (What You Need)

  • A USB Flash Drive (8 GB or larger)
  • Bliss OS 14 ISO File (Downloaded from our site)
  • Rufus tool (To create a bootable USB drive)

Step 1: Create a Bootable USB

  • Insert your USB drive into your PC.
  • Open Rufus and select your USB drive under "Device".
  • Click on "Select" and choose the downloaded Bliss OS 14 ISO file.
  • Keep the partition scheme as GPT (or MBR for older PCs) and click Start to flash.

Step 2: Change BIOS Settings

  • Restart your PC and press the BIOS key (usually F2, F12, Del, or Esc).
  • Go to the Security tab and set Secure Boot to Disabled.
  • Go to the Boot menu and set your USB Drive as the first boot priority.
  • Save the changes and exit (usually F10).

Step 3: Boot and Install Bliss OS

  • Your PC will now boot into the Bliss OS installer menu.
  • Select Installation - Install Bliss-OS to harddisk.
  • Choose the partition where you want to install it (Create a new partition if you want to dual-boot).
  • Format the partition as ext4 or NTFS.
  • When asked to install GRUB Bootloader, select Yes (Crucial for dual-booting).
  • When asked to make system directory read-write, select Yes.

Step 4: Final Setup

  • Once the installation is complete, remove the USB drive.
  • Select Reboot from the screen.
  • Your PC will restart into Bliss OS 14. Follow the on-screen instructions to set up your Android system!
